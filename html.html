Introduction

HTML (HyperText Markup Language) is the standard language for creating and structuring web pages using tags and elements.

It defines how content like text, images, and links appear in a browser.



  • It is a markup language, not a programming language.

  • This means it annotates text to define how it is structured and displayed by web browsers.

  • It is a static language, meaning it does not inherently provide interactive features but can be combined with CSS for styling and JavaScript for interactivity.

intro.html 
<h1>Welcome to HTML</h1>
<!DOCTYPE html>
<html>
<head>
    <title>My First Webpage</title>
</head>
<body>
    <h1>Welcome to My Webpage</h1>
    <p>This is my first paragraph of text!</p>
</body>
</html>

Example Explained


  • The<!DOCTYPE html> declaration defines that this document is an HTML5 document


  • The <html> element is the root element of an HTML page

  • The <head> element contains meta information about the HTML page

  • The <title> element specifies a title for the HTML page (which is shown in the browser's title bar or in the page's tab)

  • The <body> element defines the document's body, and is a container for all the visible contents, such as headings, paragraphs, images, hyperlinks, tables, lists, etc.

  • The <h1> element defines a large heading

  • The <p> element defines a paragraph

HTML Basics

HTML (HyperText Markup Language) is the standard markup language used to create and structure web pages. It defines the layout of a webpage using elements and tags, allowing display of text, images, links, and multimedia.

HTML is used in over 95% of websites, making it essential for modern web development.

HTML Elements

HTML elements are the building blocks of a webpage. They define structure and content using opening tags, content, and closing tags.

  • Every element has an opening and closing tag
  • Elements can contain text, attributes, or other elements
  • Some elements are self-closing like <br>, <img>
  • Proper nesting is important for correct structure

Syntax of HTML Element

syntax.html 
<tagname>Your Content</tagname>

  • Closing tag: </tagname>
  • Content is placed between them

Case Sensitivity

HTML is not case-sensitive. But best practice is to use lowercase tags.

HTML Attributes

HTML Attributes are special words used inside the opening tag of an element. They provide extra information about HTML elements and control their behavior, appearance, or functionality.

  • Each attribute has a name and a value → name="value"
  • Attributes tell the browser how an element should behave
attribute.html 
<img src="image.png" style="width:300px;">

Syntax

<tagname attribute="value"> Content </tagname>

Components of Attributes

  • Attribute Name: Defines property (e.g., src, href)
  • Attribute Value: Defines value of property

Common HTML Attributes

Attribute Description
src Specifies source of image, video, etc.
href Specifies link destination
alt Alternative text for images
id Unique identifier for element
class Used for styling and grouping
style Inline CSS styling
title Tooltip text on hover
lang Defines language of content

Example: Image Attribute

img.html 
<img src="image.png" alt="Sample Image" width="300">

Example: Link Attribute

link.html 
<a href="https://example.com" target="_blank">
Click Here
</a>

Important Points

  • Always use lowercase for attributes
  • Always use quotes around values
  • Boolean attributes (like checked) don’t need value
  • Use CSS instead of old attributes like align, bgcolor

Conclusion

HTML attributes make elements powerful and flexible. They allow you to control how elements behave and appear on a webpage. Mastering attributes is essential for building modern and interactive websites.

HTML Paragraphs

A paragraph in HTML is a block of text enclosed within the <p> tag. It helps divide content into readable sections and improves the structure of a webpage.

  • Adds space before and after text
  • Creates clean and readable content blocks
paragraph.html 
<p>A Computer Science portal for geeks.</p>
<p>It contains well written articles.</p>

Properties of <p> Tag

  • Multiple spaces are reduced to a single space
  • Extra line breaks are ignored
  • Each paragraph starts on a new line
  • Default display is block
spacing.html 
<p>
This paragraph has multiple lines.
But HTML shows it as a single line.
</p>

Line Break <br>

The <br> tag creates a new line without starting a new paragraph.

break.html 
<p>
Line 1<br>
Line 2<br>
Line 3
</p>

Horizontal Line <hr>

The <hr> tag creates a horizontal line to separate content.

hr.html 
<p>First Section</p>
<hr>
<p>Second Section</p>

Alignment (Deprecated)

The align attribute was used to align text (left, center, right), but it is now deprecated. Use CSS instead.

align.html 
<p align="center">Centered Text</p>

Best Practices

  • Do not nest <p> tags inside each other
  • Use <br> for small line breaks
  • Use CSS instead of align attribute
  • Use <pre> tag if you want exact spacing

Conclusion

Paragraphs are essential for structuring text on a webpage. They improve readability and help organize content effectively.

Block & Inline Elements

HTML elements are divided into two main types: Block-level and Inline elements. This difference controls how elements appear and behave on a webpage.

Key Difference

  • Block Elements: Start on a new line and take full width
  • Inline Elements: Stay in the same line and take only needed space

Example

example.html 
<div>This is a block element</div>

Text before 
<a href="#">Click Here</a> 
Text after

Block-Level Elements

Block elements always start on a new line and take full width of the page. They are mainly used for layout and structure.

  • <div>
  • <p>
  • <h1> to <h6>
  • <section>
  • <article>
  • <nav>
  • <ul>, <ol>, <li>
  • <table>

Example: Block Element

block.html 
<div>
    <h2>Heading</h2>
    <p>This is inside a div</p>
</div>

Inline Elements

Inline elements do not start on a new line and only take the width required. They are used to style or format text inside block elements.

  • <span>
  • <a>
  • <img>
  • <strong>
  • <em>
  • <input>
  • <br>

Example: Inline Element

inline.html 
<p>
This is a <span>span element</span> inside text.
</p>

Difference Table

Block Elements Inline Elements
Start on new line Stay in same line
Take full width Take only needed width
Used for layout Used for styling text

Conclusion

Understanding block and inline elements helps you design better layouts and structure your webpage properly. Most HTML designs are built using these two types.

HTML Links (Hyperlinks)

HTML links, also known as hyperlinks, are used to connect one web page to another. They allow users to navigate between pages, websites, or sections easily.

  • <a> → Anchor tag used to create links
  • href → Specifies the destination URL
  • target → Defines where to open the link
  • title → Adds extra information on hover

Basic Example

links.html 
<p>Click on the link below:</p>

<a href="https://www.example.com">
    Visit Website
</a>

Default Link Behavior

  • Unvisited link → Blue & underlined
  • Visited link → Purple & underlined
  • Active link → Red & underlined

Target Attribute

The target attribute specifies where the link will open.

  • _blank → Opens in new tab
  • _self → Opens in same tab (default)
  • _parent → Opens in parent frame
  • _top → Opens in full window
target.html 
<a href="https://www.example.com" target="_blank">
    Open in New Tab
</a>

<a href="https://www.example.com" target="_self">
    Open in Same Tab
</a>

Linking Different Elements

  • Image Link
  • Email Link
  • Phone Link
  • Button Link
  • Download Link

HTML links are essential for navigation on websites. They can connect pages, files, emails, and even phone numbers, making web browsing interactive and user-friendly.

HTML Video

The HTML <video> tag is used to embed video content in a web page. It allows users to play videos directly in the browser without needing external plugins.

  • <video> → Defines the video player
  • <source> → Specifies video file
  • controls → Adds play, pause, volume buttons
  • autoplay → Plays video automatically
  • loop → Repeats the video
  • muted → Mutes the video

Basic Syntax

video.html 
<video controls>
    <source src="movie.mp4" type="video/mp4">
    Your browser does not support the video tag.
</video>

Basic Example

basic-video.html 
<h3>Sample Video</h3>

<video width="400" controls>
    <source src="sample.mp4" type="video/mp4">
</video>

Video Attributes

  • controls → Shows video controls
  • autoplay → Plays automatically
  • loop → Repeats video
  • muted → Mutes audio
  • width / height → Sets video size

Example with Attributes

attributes.html 
<video width="400" controls autoplay muted loop>
    <source src="video.mp4" type="video/mp4">
</video>

Multiple Video Sources

You can add multiple video formats to support different browsers.

multiple.html 
<video controls>
    <source src="video.mp4" type="video/mp4">
    <source src="video.webm" type="video/webm">
    Your browser does not support the video tag.
</video>

Conclusion

The HTML video tag makes it easy to add videos to web pages. With attributes like controls, autoplay, and loop, you can fully control video behavior and improve user experience.

</table>

Conclusion

HTML tables are used to organize and display data clearly. With features like borders, spacing, and merging cells, tables become powerful for structured content.

HTML Iframes

An iframe (Inline Frame) is used to embed another webpage inside your current webpage. It acts like a window that displays external content such as websites, videos, or maps.

  • <iframe> → Embeds another webpage
  • src → URL of the page to display
  • width / height → Sets iframe size
  • name → Used to target iframe with links

Basic Syntax

iframe.html 
<iframe src="https://www.example.com"></iframe>

Basic Example

basic.html 
<h3>Embedded Website</h3>

<iframe src="https://www.example.com"
        width="400"
        height="300">
</iframe>

Iframe Attributes

  • src → Specifies URL
  • width → Width of iframe
  • height → Height of iframe
  • allowfullscreen → Enables fullscreen mode
  • loading → Lazy loading of iframe

Remove Border

noborder.html 
<iframe src="https://www.example.com"
        width="400"
        height="300"
        style="border: none;">
</iframe>

Styled Border

style.html 
<iframe src="https://www.example.com"
        width="400"
        height="300"
        style="border: 3px solid orange;">
</iframe>

Target Iframe with Link

You can load different pages inside an iframe using links.

target.html 
<iframe src="page1.html"
        width="400"
        height="300"
        name="myFrame">
</iframe>

<br>

<a href="page2.html" target="myFrame">
    Load Page 2
</a>

Use Cases

  • Embedding YouTube videos
  • Adding Google Maps
  • Loading external websites
  • Displaying forms or widgets

Conclusion

HTML iframes allow embedding external content inside a webpage. They are useful for videos, maps, and third-party content, but should be used carefully for performance and security.

HTML File Paths

HTML File Paths tell the browser where to find resources like images, videos, scripts, and other files. They ensure that all required files load correctly on a webpage.

  • File paths locate external resources
  • Used in attributes like src and href
  • Helps load images, videos, CSS, and JS files

Basic Syntax

syntax.html 
<img src="path/image.jpg" alt="description">

Absolute File Path

An absolute path uses the full URL including domain name.

absolute.html 
<img src="https://example.com/image.jpg" alt="Image">
  • Uses full URL (http/https)
  • Best for external resources
  • Works from anywhere

Relative File Path

A relative path depends on the current file location.

relative.html 
<img src="images/photo.jpg" alt="Image">
  • Used for internal files
  • Makes website portable

Directory Navigation

paths.html 
<img src="./image.jpg">   
<img src="../image.jpg">  
<img src="/images/img.jpg">
  • ./ → Current directory
  • ../ → One level up
  • / → Root directory

Best Practices

  • Use relative paths for internal files
  • Keep folder structure clean
  • Avoid spaces in file names
  • Always test paths properly

Conclusion

File paths are essential for linking resources in HTML. Using correct paths ensures your website loads all assets properly and works smoothly.
